BACKGROUND RECIPE

  • Canvas size: 640 × 480 px
  • Base fill: linear gradient #102080 (top) → #001040 (bottom)
  • Panel/card areas: #26235a at varying opacity (30–60%)
  • Venue silhouettes: paint in #001040 at 30–50% opacity — shadow detail only
  • Text-safe zone: inner ~560 × 320 px — keep outer edges for background detail
  • Do NOT bake scanlines into PNGs — CSS applies them as an overlay
  • Font family: Star4000, Star4000 Large, Star4000 Small, Star4000 Extended
